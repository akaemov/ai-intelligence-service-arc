# Исследование спроса на коммерческие услуги в России

[Публичный сайт](https://akaemov.github.io/ai-intelligence-service-arc/) · [Запустить исследование](https://github.com/akaemov/ai-intelligence-service-arc/actions/workflows/research.yml)

Российский сервис исследования маркетинга, рекламы, ИИ и коммерческой аналитики. Девять разделов, фильтры реестра, экспорт CSV/JSON, происхождение каждого факта и история запусков. Режим по умолчанию — Россия, 90 дней; отдельные режимы регионов и отраслей. Башкортостан — один из регионов справочника.

Реальный сбор: четыре доступных независимых источника, две группы, два прямых канала (Workspace и Weblancer). HH возвращает 403, ЕИС — 503. После дедупликации получены 22 наблюдения: 21 запрос и один контекстный материал. У запросов не подтверждена российская география заказчика; они видны в реестре, но не превращаются в показатели российского спроса. Полнота рынка и архива за 90 дней не подтверждена. [Подробный отчёт](docs/russia-run.md).

## Запуск

Python 3.11+, Node 22+. Python не требует сторонних пакетов.

```bash
npm --prefix web ci --ignore-scripts
python -m unittest discover -s tests -v
npm --prefix web test
python -m src.run
npm --prefix web run build
npm --prefix web run dev
```

Выход сборщика 0 означает успешный доступ ко всем выбранным источникам, 2 — частичное/неуспешное покрытие; изучите `web/public/data/attempt.json`. Ошибка доступа не означает отсутствие спроса. Внутренние SQLite, кэш и контрольные точки находятся в ignored `.state/`; публикация проходит проверку контактов и секретов.
