# Исследование спроса на коммерческие услуги в Башкортостане

Система ручного сбора открытых данных и доказательного обзора спроса на маркетинг, рекламу, ИИ и коммерческую аналитику. Русскоязычный адаптивный интерфейс: обзор, услуги, аудитория, география, конкуренты, возможности, реестр с фильтрами/CSV/JSON, методология и история.

**Текущий статус:** локальные тесты, сборка и браузерная проверка выполнены; реальный сбор имеет частичное покрытие. Башинформ и РБК доступны; HH-поиск возвращает 403, ЕИС 503. Требуемые три независимых источника в двух группах и рабочий прямой канал пока не подтверждены. Наблюдения не подменяются демоданными. Автоматическая публикация по умолчанию выключена. Репозиторий публичный; GitHub Pages включён для ветки `gh-pages`. [Сайт](https://akaemov.github.io/ai-intelligence-service-arc/) показывает текущий частичный отчёт. [Инструкции публикации](docs/github.md).

## Быстрый запуск

Python 3.11+, Node 22+:

```bash
npm --prefix web ci --ignore-scripts
python -m unittest discover -s tests -v
npm --prefix web test
python -m src.run
npm --prefix web run build
npm --prefix web run dev
```

Сбор с частичным покрытием возвращает 2. Отчёт: web/public/data/attempt.json; внутренняя история/SQLite — ignored .state/. Бюджеты неизвестны, если нет подтверждённой суммы. Вакансии — потребность в компетенциях, не заказ подрядчику. Отсутствие данных не отсутствие спроса.
