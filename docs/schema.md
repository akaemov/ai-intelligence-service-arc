# Схема

Observation — типизированная dataclass с runtime-валидацией; JSON Schema в schemas/observation.schema.json.
Обязательны ID, ID запуска, источник и URL, заголовок, время сбора, тип сигнала, уверенность, hash. Неизвестные поля — null. Источник фактов: короткая выдержка, URL, дата; аналитическое предположение хранится отдельно.

A — прямой спрос; B — поисковый интерес (только измеренный API-показатель); C — косвенная потребность; D — предложение; E — контекст; F — нерелевантно. Вакансии имеют subtype vacancy. Региональные показатели учитывают только подтверждённую географию, подходящий период и категории; B2B/неизвестный/частный сегменты разделяются.

Дедупликация: canonical URL либо hash нормализованного заголовка/выдержки; независимость подтверждений определяется доменом, а не числом публикаций. Это консервативная эвристика: перефразированные перепечатки требуют ручной проверки.

Метаданные опроса — отдельный survey объект: организатор, даты, размер/состав выборки, вопрос, метод и ограничения. Неизвестная методика исключает представительные выводы.
