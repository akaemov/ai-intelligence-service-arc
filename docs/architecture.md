# Архитектура

Python collector → normalizer/classifier → factual verifier → дедупликация → SQLite → analyst → privacy gate → атомарный JSON → TypeScript/Vite.

`src/run.py` принимает конфигурацию, назначает UUID, сохраняет контрольные точки и журналирует каждый источник. Прямые каналы обрабатываются раньше вакансий и СМИ. Бюджеты времени, запросов и страниц ограничены на весь запуск и каждый источник. Квота региона применяется одинаково к Москве, Санкт-Петербургу и другим регионам; неизвестная география имеет отдельную квоту. Это ограничения выборки, не веса рынка.

`src/processing/geography.py` проверяет текущий справочник HH, сохраняет происхождение, hash и дату. HH IDs не смешиваются с ФИАС/ОКАТО. Неоднозначный город и неизвестный округ остаются неизвестными. [Федеральная модель](architecture-russia.md).

HTML разбирается инертным стандартным парсером; код страницы не выполняется. Проверяется robots.txt, запросы ограничены разрешёнными HTTPS-хостами, TLS и ограничения доступа сохраняются. При ошибке источник получает явный статус; частично выполненный источник не выдаётся за полный.

Публичные `latest.json` и `attempt.json` содержат только проверенные записи, безопасные короткие цитаты и журнал покрытия. Внутренняя SQLite и raw-кэш не экспортируются. Последний доступный отчёт сохраняется при полном отказе. `scripts/publish_branch.py` публикует только проверенный каталог через отдельный индекс Git, без создания worktree.
