# Архитектура и границы

CLI → collector → normalizer → classifier → verifier → SQLite → analyst → privacy gate → JSON/CSV → Vite.
Каждый запуск имеет UUID, параметры, журнал покрытия каждого адаптера и ошибки. Внутренние данные находятся в ignored `.state/`; публикация содержит только минимальные выдержки и публичные поля. Никаких демоданных в сайте.

Сначала сбор официального API вакансий HH и обнаруживаемых RSS Башинформ/РБК. Канал прямого спроса — открытый поиск ЕИС закупок; регион проверяется по тексту каждого результата, числовые идентификаторы не угадываются. Страницы читаются только после robots.txt; авторизация и CAPTCHA не обходятся. URL RSS считается проверенным только после успешной XML-проверки. Неподтверждённые/заблокированные источники сохраняют соответствующий статус.

Вакансии — косвенный сигнал компетенций; не покупки услуг. Новости — контекст. Прямой спрос требует явного запроса заказчика и регионального основания. Неизвестные бюджет, отрасль и сегмент остаются null. LLM не требуется для основного конвейера; без проверенной интеграции генеративная интерпретация отключена.

Публикуется только завершённый набор, атомарной заменой файла. Ошибка оставляет предыдущий сайт и результаты. Запуски сериализуются файловой блокировкой; GitHub Actions имеет concurrency. HTTP: TLS-проверка, ограниченные ответы, таймауты, задержки, ограниченные retries, кэш. Исследование ограничено покрытием, а не описывает весь рынок.
