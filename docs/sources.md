# Источники и покрытие

| Источник | Доступ и метод | Ограничение |
|---|---|---|
| Workspace | Разрешённая главная, реальные ссылки заданий и явные бюджетные диапазоны | Индекс и карточки /tenders/ запрещены robots.txt, не читаются; дата/география на главной не подтверждены |
| Weblancer | Открытая главная и категории, найденные на ней; изолированные карточки, даты | Международная площадка; страна/сегмент заказчика часто неизвестны; профили не собираются |
| Башинформ | Разрешённая главная; дата URL; тематическая статья с явным местом события | СМИ дают контекст, не покупательский спрос; архив не обследован |
| CNews — ИТ-бизнес | Официальный RSS biz.xml обнаружен на главной, robots.txt разрешает | Заголовки, даты и ссылки, до 150 текущих записей; только контекст, российская география не предполагается по домену |
| РБК | Открытая RSS-лента | До 150 текущих элементов, архив не обследован; в запуске тематических материалов нет |

Независимость определяется оператором, не количеством URL. Статус успешного доступа означает работу выбранного метода, не полноту площадки. Поисковая статистика, опросы, социальные обсуждения, компании, отзывы и справочники конкурентов зарегистрированы в `config/source-groups.json`, но не представлены как подключённые каналы. Дополнительная проверка B2B-center дала 403; обход не выполняется.

Все страницы — недоверенные данные. Только открытый доступ, соблюдение robots.txt, лимиты, отсутствие обхода CAPTCHA/авторизации. Контакты частных лиц, профили, внутренние raw-страницы и секреты не публикуются. Подробнее о фактическом сборе: [Россия](russia-run.md), [первый исторический региональный запуск](first-run.md).

HH-поиск (403) и ЕИС (503) исключены из активного списка и не запрашиваются. Диагностика сохранена в `config/excluded-sources.json`, а исторические отчёты сохраняют фактическое прежнее покрытие. Доступный официальный HH /areas используется отдельно только как справочник географии, без поиска вакансий.

Перед включением новых каналов выполнена проверка из GitHub Actions. RSS Freelance.ru недоступен, а на проверенной странице Хабра RSS не обнаружен: эти кандидаты не подключены.
