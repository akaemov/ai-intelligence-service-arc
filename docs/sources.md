# Источники и расширение

| Источник | Доступ | Реальная проверка | Ограничения |
|---|---|---|---|
| Башинформ | robots.txt + открытая главная | Успешно; обнаружены датированные ссылки /news/ | RSS на главной не найден, используется HTML; только текущая главная, не 90-дневный архив; выдержки до 280 символов |
| РБК | официальный RSS | Успешно, 30 элементов | Национальный контекст; без регионального основания не спрос; нет архивного поиска |
| HH | официальный API /areas и /vacancies | Справочник успешен: Башкортостан 1347; поиск вакансий 403 forbidden | ID получен из справочника, не зашит; возможны ограничения API/приложения; период API не более 30 дней; вакансии не внешний заказ |
| ЕИС | robots.txt + публичные результаты | HTTP 503 | Канал прямого спроса не подтверждён; парсер не проверен на успешном текущем ответе; без обхода ограничений |

Реестр в config/research.json. Не добавляйте площадку, пока не проверены её существование, условия, robots.txt, официальный метод и ограничения. Наличие адаптера не означает успешное подключение. Связанный отчёт хранит статус, ошибки, последнее успешное время и фактический метод.

Расширяемые группы: поиск/статистика запросов, СМИ, опросы, официальная статистика, публичные соцсети, разрешённые публичные обсуждения, сайты компаний/объединений, каталоги/карты, отзывы, объявления/исполнители, закупки, вакансии, региональные/отраслевые агрегаторы. Сейчас реализованы СМИ, вакансии и закупки; остальные не подключены, URL/API для них не выдуманы. Для нового адаптера добавьте описание в реестр, функцию в src/collectors/adapters.py и ADAPTERS, разрешённый домен в HTTP.ALLOWED и настройки среды, тесты на реальный документированный формат (обезличенный fixture).

Контракт collect: (список raw-фактов, метод/границы). Raw имеет title, url, published_at; geography_evidence и verified_region только из доказанного фильтра/адреса/места исполнения. Не передавайте целую статью, контакты или пользовательские профили. Ошибки должны приводить к blocked/error, а не к пустому «успешному» результату. Платные API по умолчанию отключены, фактический расход текущих адаптеров 0.

Нужные домены: api.hh.ru, www.bashinform.ru, bashinform.ru, rssexport.rbc.ru, zakupki.gov.ru. Нужные ключи для текущих открытых адаптеров не заявлены. Для HH необходимо выяснить разрешённый доступ к поиску в официальном кабинете/API; 403 сам по себе не доказывает необходимость нового токена. Не вводите секреты в чат или Git. LLM отсутствует: provider/model предусмотрены в конфигурации, enabled=true намеренно отклоняется до реализации и проверки провайдера.
