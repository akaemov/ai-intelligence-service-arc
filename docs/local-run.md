# Локальный запуск

Из корня репозитория, Python 3.11+ и Node 22+:

```bash
npm --prefix web ci --ignore-scripts
python -m unittest discover -s tests -v
npm --prefix web test
python -m src.run
npm --prefix web run build
npm --prefix web run preview -- --port 4173
```

Сбор имеет бюджет запросов, страниц, времени и USD; значения по умолчанию в `config/research.json`. Каждый источник также ограничен квотами. Внутреннее состояние `.state/` не публикуется. Последний доступный отчёт сохраняется при полном отказе нового сбора, новая попытка видна отдельно.

```bash
python -m src.run --mode selected_regions --regions 'Республика Башкортостан,Республика Татарстан'
python -m src.run --mode industries --industries 'торговля' --max-requests 40 --max-pages 20
python -m src.run --groups requests,media --days 90 --max-seconds 180
python -m src.run --resume UUID_ПРЕРВАННОГО_ЗАПУСКА
```

Активные источники — Workspace, Weblancer, Башинформ, РБК и CNews. ЕИС и поиск HH удалены из default-конфигурации; официальный HH /areas используется только для географии. Для CNews в облачной среде нужен разрешённый домен `www.cnews.ru`; в GitHub Actions доступ проверен.

Для `--resume` параметры должны совпадать с исходными. Завершённые источники восстанавливаются из контрольных точек; незавершённые повторяются в пределах нового бюджета времени. Кэш ответов действует один час, его использование отражено в отчёте. Архив 90 дней источники могут не предоставлять.

Отраслевая/региональная фильтрация требует явных фактов. При отсутствии отрасли или региона запись остаётся в реестре, но исключается из показателей выбранного сегмента. HH area IDs получаются из текущего API `/areas`, не задаются вручную.

LLM: установите `llm.enabled`, совместимый HTTPS endpoint, модель, подтверждённые `usd_per_million_input/output` и ненулевой `max_api_budget`. `LLM_API_KEY` вводится только через защищённые настройки среды. Неизвестный тариф/отсутствующий ключ не вызывает платного запроса; генерация не заменяет факты. Домен выбранного провайдера должен быть разрешён в сети и клиенте. Не передавайте значения ключей в сообщения или файлы репозитория.

Браузерная проверка необязательна для разработки: `python scripts/browser_smoke.py` требует Playwright и локальный Chromium. Проверяет реальный отчёт, все разделы, фильтры, экспорт, мобильную ширину и ошибки JavaScript.
