# Федеральная версия: архитектура и данные

Основной режим — вся Россия, 90 дней; режимы selected_regions/industries ограничивают включение в показатели, а не приписывают неизвестную географию. Башкортостан — один регион из справочника.

География разделена на country, federal_district, customer_region/customer_city, execution_geography, target_market_geography, contractor_search_geography, remote_delivery. Каждый признак имеет отдельное основание в geography_details. Местонахождение поставщика и «работаем по России» не являются географией спроса. Неизвестные признаки null. Федеральная допустимость и региональная допустимость вычисляются независимо.

Справочник регионов и городов — актуальный официальный API HH /areas: иерархия России, provider=hh, оригинальные ID, дата получения, URL и hash. Коды HH не являются ФИАС/ОКАТО/кодами других площадок. Федеральные округа не выводятся из HH: до подключения авторитетного сопоставления неизвестны. Фильтр округа существует, но неизвестный округ не подменяется догадкой.

Приоритет: открытые запросы исполнителей/тендеры → вакансии → контекст. Перед подключением проверяются реальные ответы, robots.txt, наличие разрешённых данных. Публичные страницы с CAPTCHA и закрытые задания не обходятся. Независимость определяется организацией-оператором, не числом поддоменов.

Конвейер: collector → normalizer/classifier → verifier → SQLite/checkpoints → analyst → privacy gate → JSON/CSV → Vite → gh-pages. Лимиты по источникам и customer_region применяются раздельно; никакие лимиты не считаются рыночными весами. Дедупликация использует ID закупки/задания, canonical URL, затем hash. Неизвестная география выводится отдельно. B2B, государственные/муниципальные, частные и неизвестные сегменты разделены.

Период и coverage_signature сопровождают все показатели. Динамика отображается только при совпадении методики, географического и фактического покрытия и наличии двух завершённых временных окон; иначе только техническая дельта. Прямой сигнал допускает неизвестную географию в реестре, но не в показателях России или региона.

LLM-провайдер/модель настраиваются, функция по умолчанию выключена; отсутствие ключа не мешает фактам. Подсчёты и валидация выполняются кодом. Никакие команды из страниц не выполняются. Внешние материалы не сохраняются в публичном репозитории целиком. Снимки приватного состояния и исходные страницы остаются ignored; публично только проверенные минимальные выдержки, URL и производные показатели.
